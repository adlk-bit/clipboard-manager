# Clipboard Manager v1.1.4

This release repairs Windows launch-at-startup end to end: the installed executable is registered as a verified current-user login item, starts silently in the tray, and can be controlled from Settings.

本版本完整修复 Windows 开机自启动：安装后的程序会注册为经过确认的当前用户登录项，登录后静默驻留托盘，并可在设置中随时开关。

## Highlights / 主要更新

- Register the packaged `ClipboardManager.exe` through Electron's Windows login-item API and verify the effective system state after every change.
- Repair older installations automatically on their first v1.1.4 launch when no startup preference was previously saved.
- Add a bilingual **Launch at startup / 开机自动启动** switch to Settings.
- Reflect Windows Startup Apps deactivation accurately and respect a login item disabled by the user instead of repeatedly re-enabling it.
- Keep development and runtime-smoke executables out of the real Windows startup list.
- Add focused tests for unsupported development runs, first-run migration, explicit enable/disable, verification, and Windows-disabled entries.
- 通过 Electron 的 Windows 登录项 API 注册安装后的 `ClipboardManager.exe`，每次更改后读取系统实际生效状态进行确认。
- 旧版本未保存启动偏好时，首次运行 v1.1.4 会自动补建登录项。
- 设置页新增中英双语“开机自动启动”开关。
- 准确识别 Windows“启动应用”中的禁用状态，尊重用户在系统中的关闭选择，不会反复强制启用。
- 开发进程与隔离运行测试不会写入真实 Windows 启动列表。
- 新增开发版限制、首次迁移、显式启停、写入确认及系统禁用状态等专项测试。
