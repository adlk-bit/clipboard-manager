# Clipboard Manager v1.1.1

This release fixes the appearance switch and adds a persistent bilingual desktop interface, together with project-maintenance and security improvements.

本版本修正外观模式拨钮，并加入可持久化的中英文桌面界面，同时完善项目维护与安全基础设施。

## Highlights / 主要更新

- Fixed the dark-mode switch direction; the thumb now follows the selected state consistently. The verification-code switch uses the same geometry.
- Added a Simplified Chinese / English selector in Settings. The desktop UI, tray menu, dialogs, and native prompts switch immediately and retain the choice after restart.
- Added GitHub Actions for desktop tests, TypeScript checking, production builds, Android unit tests, and Android lint.
- Added `SECURITY.md`, `CONTRIBUTING.md`, Issue/PR templates, a real runtime screenshot, architecture documentation, a privacy threat model, and a maintainer automation proposal.
- 修正深色模式拨钮方向，并统一验证码开关的拨钮结构。
- 设置中新增简体中文 / English 切换，桌面界面、托盘、对话框与原生提示会即时切换并跨重启保留。
- 新增桌面端与 Android 的持续集成检查，以及安全、贡献、Issue/PR 模板、真实截图、架构和隐私威胁模型文档。

## Downloads / 下载

- Windows installer: `ClipboardManager-Setup-1.1.1.exe`
- Windows updater metadata: `latest.yml` and `ClipboardManager-Setup-1.1.1.exe.blockmap`
- Android companion: `ClipboardManager-Android-1.1.1.apk`

Use phone pairing only on a trusted private LAN. Android notification access remains opt-in and is used only for the verification-code relay described in the project documentation.

手机配对请仅在可信的私有局域网中使用。Android 通知访问仍需用户主动授权，并仅用于项目文档所述的验证码转发。
