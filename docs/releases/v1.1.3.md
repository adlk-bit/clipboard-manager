# Clipboard Manager v1.1.3

This release adds privacy-first preview masking, richer history search, and a persistent always-on-top window control while preserving the project's local-first data model.

本版本新增隐私优先的预览脱敏、更完整的历史搜索和可持久化的窗口置顶，同时保持项目本地优先的数据模型。

## Highlights / 主要更新

- Mask mainland China phone numbers, email addresses, ID numbers, Luhn-valid bank cards, labelled passwords/tokens, Bearer tokens, and AWS access keys in history previews.
- Copy operations still use the original content; protected cards can be revealed temporarily, and masking can be disabled in Settings.
- Search clipboard text, favorite folders, and tags from the same compact search field, including metadata attached to image favorites.
- Keep the desktop window above other windows with a persisted title-bar control and confirmed Windows state transitions.
- Back up and restore the new privacy and window preferences with the existing portable backup format.
- Extend isolated Electron runtime validation for masked/revealed content, metadata search, settings, and always-on-top persistence without touching the real user database.
- 在历史预览中自动隐藏中国大陆手机号、邮箱、身份证、通过 Luhn 校验的银行卡、带标签的密码/Token、Bearer Token 和 AWS Access Key。
- 复制操作仍使用原始内容；可按卡片临时显示敏感内容，也可在设置中关闭预览脱敏。
- 顶部搜索框可同时检索文字内容、收藏目录和标签，也能通过元数据找到图片收藏。
- 标题栏新增可持久化的窗口置顶按钮，并确认 Windows 原生置顶状态后再更新界面。
- 便携备份会包含新的隐私和窗口偏好设置。
- 隔离 Electron 运行验证新增脱敏/显示、元数据搜索、设置及置顶跨重启检查，不触碰真实用户数据库。

## Downloads / 下载

- Windows installer: `ClipboardManager-Setup-1.1.3.exe`
- Windows updater metadata: `latest.yml` and `ClipboardManager-Setup-1.1.3.exe.blockmap`
- Android companion: `ClipboardManager-Android-1.1.3.apk`

Sensitive masking protects the on-screen preview only; it is not at-rest database encryption. Use phone pairing only on a trusted private LAN.

敏感内容脱敏仅保护屏幕预览，并非数据库静态加密。手机配对请仅在可信的私有局域网中使用。
