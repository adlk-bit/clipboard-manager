# Clipboard Manager v1.1.2

This maintenance release removes redundant packaged output and improves Windows installer compression without changing Clipboard Manager's core functionality.

本维护版本清理打包产物中的冗余内容并提高 Windows 安装包压缩率，不改变 Clipboard Manager 的核心功能。

## Highlights / 主要更新

- Package only the electron-vite main, preload, and renderer runtime bundles instead of stale TypeScript source/declaration output.
- Keep only the runtime tray icon in `app.asar`, remove the unused `concurrently` development dependency, and use maximum NSIS compression.
- Use electron-builder's standard Electron packaging path so the redundant default-app payload is not copied into the installed application.
- `app.asar`: 1,020,023 -> 630,444 bytes (-38.2%).
- Windows installer: 91,989,366 -> 91,789,554 bytes (-199,812 bytes / -0.22%).
- Unpacked Windows application: 318,207,742 -> 317,707,084 bytes (-500,658 bytes / -0.16%).
- 仅打包 electron-vite 生成的主进程、预加载和渲染进程运行目录，排除残留的 TypeScript 源码、声明文件与构建信息。
- `app.asar` 仅保留运行时托盘图标，移除未使用的 `concurrently` 开发依赖，并使用 NSIS 最高压缩级别。
- 改用 electron-builder 标准 Electron 打包路径，不再复制冗余的默认应用载荷。
- 本次只调整依赖与打包边界；剪贴板历史、图片、收藏、备份、Emoji、手机同步、验证码转发、双语界面和快捷键功能均保留。

## Downloads / 下载

- Windows installer: `ClipboardManager-Setup-1.1.2.exe`
- Windows updater metadata: `latest.yml` and `ClipboardManager-Setup-1.1.2.exe.blockmap`
- Android companion: `ClipboardManager-Android-1.1.2.apk`

Use phone pairing only on a trusted private LAN. Android notification access remains opt-in and is used only for the verification-code relay described in the project documentation.

手机配对请仅在可信的私有局域网中使用。Android 通知访问仍需用户主动授权，并仅用于项目文档所述的验证码转发。
