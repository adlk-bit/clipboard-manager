# Clipboard Manager v1.2.1

Reuse common replies, paste text records in sequence, and find text inside screenshots. This release adds the five follow-up productivity features and fixes Windows always-on-top confirmation and shutdown persistence.

复用常用回复、按顺序粘贴多条记录、直接检索截图文字。本版本完成五项后续效率功能，并修复 Windows 窗口置顶确认和退出前的数据保存。

## Highlights / 主要更新

- **Phrases and templates:** save independently from history, fill repeated variables, use current date/time defaults, and preview before copying. Titles and list previews support sensitive-content masking.
- **Sequential paste queue:** select up to 100 text records, focus the destination, and press `Ctrl+Shift+Alt+V` for each item. Pause, skip, rewind and choose a new target; check the target window/process and clipboard sequence before sending input.
- **Capture and window reliability:** use Windows clipboard notifications and lightweight sequence checks to avoid encoding unchanged images. Confirm topmost using the native window state, and flush pending data on tray exit.
- **Local OCR:** use installed Windows language features to recognize images without uploading them. Search the local index, edit before copying, and remove individual or all indexes.
- **Source filters and exclusions:** filter history by app name and exclude exact process names. With exclusions enabled, unknown sources are skipped, including when the native helper is unavailable.
- **Portable data:** backup format 2 includes templates, OCR indexes, source metadata and exclusion rules; importing format 1 and legacy JSON remains supported.
- Synchronize the Android companion to **1.2.1 / version code 8**, with no changes to phone features.

- **常用短语与模板：** 独立于历史保存，填写重复变量、当前日期和时间，预览后复制；标题和列表预览沿用敏感内容遮罩。
- **顺序粘贴队列：** 多选最多 100 条文字，切到目标应用后按 `Ctrl+Shift+Alt+V` 逐条粘贴；支持暂停、跳过、退一条、重选目标，并在发送前核对窗口、进程和剪贴板序号。
- **采集与窗口稳定性：** 剪贴板通知结合轻量序号检查，避免反复编码静止图片；使用 Windows 原生状态确认置顶，托盘退出前保存待写入数据。
- **本地 OCR：** 使用已安装的 Windows 识别语言，不上传图片；识别结果支持搜索、编辑后复制以及单项/全部索引清理。
- **来源筛选与排除：** 按应用名筛选，按进程名精确排除。启用排除规则时，来源未知的内容也会跳过，包括辅助模块不可用的情况。
- **可移植数据：** 格式 2 备份纳入模板、OCR 索引、来源与排除规则，继续兼容导入格式 1 和旧 JSON。
- Android 配套端同步为 **1.2.1 / 版本代码 8**，手机功能不变。

## Compatibility / 使用边界

- OCR requires the relevant Windows language OCR feature and may misrecognize characters, formulas or tables. Review the editable preview. Images stay on the device; no OCR models are bundled or downloaded by the app.
- The queue sends text only. Back rewinds queue progress without undoing text already pasted. It does not automatically press Tab/Enter or submit forms. Elevated applications may reject input; uncertain results pause the queue.
- Older app versions cannot read format 2 backups. Keep an older backup if you need to return to v1.2.0.

- OCR 需要对应的 Windows 语言识别功能，可能误识别汉字、公式或表格；复制前可在预览框校对。图片留在本机，应用不捆绑或下载识别模型。
- 队列只发送文字；“退一条”不撤销目标里已粘贴的内容，不自动按 Tab/Enter 或提交表单。管理员窗口可能拒绝输入；结果不确定时队列暂停。
- 旧版应用不能读取格式 2 备份。若需要退回 v1.2.0，请保留旧格式备份。
