# Clipboard Manager 1.3.0 for Windows

## 中文

- 历史页更新浅色和深色主题。搜索框、文字／链接／图片筛选和复制按钮可直接使用，拉宽窗口后侧栏会显示功能名称。
- 图片筛选在数据库中先排除文字记录。打开历史页时跳过图片空间统计，减少启动和输入搜索词时的重复工作。
- 提供 Windows x64 离线安装包。支持的 NTFS 卷会对程序文件启用 LZX 压缩，Chromium 的完整第三方声明随包保存在 `LICENSES.chromium.zip` 中。
- Windows 安装包未进行 Authenticode 签名，首次打开时可能出现 SmartScreen 提示。请从本页下载，并使用随附的 SHA-256 校验文件核对下载内容。

## English

- The history view has refreshed light and dark themes, a full-width search box, type filters and per-item copy controls. Wider windows show navigation labels.
- Image filtering now discards text rows in the database. Storage statistics load on the Settings page, and typing in search avoids redundant source-app queries.
- The offline Windows x64 installer uses LZX compression for program files on supported NTFS volumes. The full Chromium notices are included in `LICENSES.chromium.zip`.
- The Windows installer is unsigned. SmartScreen may warn on first launch. The accompanying SHA-256 file lets you verify your download.
