# Clipboard Manager v1.0.5

## 中文

v1.0.5 重点提升数据安全、隐私控制与日常使用可靠性：

- 新增完整便携 `.clipbackup` 备份，包含文字、图片、贴图库、收藏整理信息与安全设置，支持合并或覆盖恢复，并兼容旧版 JSON。
- 恢复历史工具栏与托盘中的暂停/恢复记录功能；暂停状态会跨重启保留，暂停期间复制的内容不会在恢复后补录。
- 修复快捷键区域点击后无法稳定进入录入状态的问题。
- 修正深色模式下侧栏、标题栏与卡片的透明度样式。
- “最新”排序、容量清理与过期清理改为依据最近使用时间，并同步清理关联图片与孤儿资源。
- 数据库使用原子写入与上一份完整快照自动恢复；渲染进程启用沙箱、Web Security 与 CSP，并收紧本地资源和 IPC 边界。

验证：5 项自动化测试、主进程与前端类型检查、生产构建、安装包构建、暂停状态重启恢复，以及打包后启动检查均已通过；深色模式与快捷键交互由用户实际检查确认。

## English

v1.0.5 focuses on safer data handling, privacy control, and day-to-day reliability:

- Added portable `.clipbackup` archives containing text, images, stickers, favorite metadata, and safe settings, with merge/replace restore and legacy JSON compatibility.
- Restored pause/resume capture controls in the history toolbar and tray. The state persists across restarts, and content copied while paused is never captured retroactively.
- Fixed reliable click-to-record behavior for custom global hotkeys.
- Corrected sidebar, title-bar, and card transparency in dark mode.
- Updated recent ordering, capacity eviction, and expiry cleanup to follow last-used time while removing linked images and orphaned managed assets.
- Added atomic database writes with last-known-good recovery, renderer sandboxing, Web Security, CSP, and tighter local-asset and IPC boundaries.

Verification: five automated tests, main/renderer type checks, production build, installer build, pause-state restart restore, and packaged startup checks passed. Dark mode and hotkey interaction were also confirmed in the real UI by the user.
