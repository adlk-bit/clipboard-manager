# Clipboard Manager v1.2.0

Find, combine, and reuse copied text with fewer steps. This release adds type filters, multi-keyword search, keyboard quick copy, merge previews, and reversible text tools while reducing unnecessary rendering and file scans.

更快查找、合并和复用复制内容。本版本加入类型筛选、多关键词搜索、键盘快速复制、合并预览与可撤销的文本工具，并减少不必要的界面刷新和文件扫描。

## Highlights / 主要更新

- Filter All / Text / Links / Images and combine space-separated keywords across content, favorite folders, and tags. `%` and `_` are searched literally; outdated search requests cannot replace newer results.
- Use `Ctrl+F` to search, `↑/↓` to select, `Enter` to copy and hide, and `Ctrl+1`–`Ctrl+9` to copy the first nine results. IME composition and dialogs are protected from background shortcuts.
- Select multiple text records from the top **Manage** toolbar and merge them with newline, blank-line, comma, or tab separators; preview or reverse the order before copying.
- Trim lines, remove blank or duplicate lines, join into one line, change case, and format/minify JSON. Undo/reset are available; JSON numbers, duplicate keys, and escapes are preserved.
- Keep original history records unchanged. Modified text over 10,000 characters is explicitly blocked instead of silently truncated.
- Keep sensitive original text out of copy notifications. Reduce card updates during navigation/selection and refresh image storage statistics only when needed in Settings.
- Synchronize the Android companion to 1.2.0 / version code 7 without changing phone features.

- 按全部 / 文字 / 链接 / 图片筛选；空格分隔多个关键词，可同时匹配内容、收藏目录和标签。`%`、`_` 按原字符查找；旧请求不会覆盖新搜索结果。
- `Ctrl+F` 搜索、`↑/↓` 选择、`Enter` 复制并收起、`Ctrl+1`–`Ctrl+9` 快速复制前九条。输入法选字与弹窗编辑不会触发后台复制。
- 从顶部“批量管理”选择多条文字，以换行、空行、逗号或制表符合并；复制前可预览或倒序。
- 新增去首尾空白、去空行、按行去重、合为一行、大小写转换、JSON 格式化/压缩；支持撤销/重置，保留 JSON 数值精度、重复键与转义。
- 原始历史记录不会被覆盖；修改结果超过 10,000 字会明确提示并禁止复制，不静默截断。
- 复制提示不泄露敏感原文；减少导航/多选时的卡片刷新，仅在设置页按需更新图片占用统计。
- Android 配套端同步为 1.2.0 / 版本代码 7，手机功能不变。
